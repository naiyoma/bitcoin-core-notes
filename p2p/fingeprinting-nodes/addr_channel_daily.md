# Per-day addr channel split — both nodes

Cut where Core's own relay gate cuts (`net_processing.cpp` `ProcessAddrs`):

```cpp
if (addr.nTime > current_time - 10min && !peer.m_getaddr_sent
        && vAddr.size() <= 10 && addr.IsRoutable()) {
    RelayAddress(pfrom.GetId(), addr, reachable);
}
```

`vAddr.size() <= 10` is a per-**message** test, so whole messages are classified
by their logged size: **`<=10` = gossip / relayed self-announcement**, **`>=11` =
getaddr reply**. Read from the complete `debug.log` of each node (archived and
sha256-verified), re-cutting the node's own arbitrary `>=990` label.

Generated by `addr_channel_daily.py`. Caveat: `size<=10` is necessary but not
sufficient for the relay gate — it also needs `!m_getaddr_sent` and
`nTime > now-10min`; we only send getaddr to outbound peers and most gossip
arrives inbound, so the leakage is second-order.
