# Per-day getaddr vs gossip — both nodes

Counted from Bitcoin Core's **stock** log line (no experiment patch involved):

```
Received addr: 1000 addresses (1000 processed, 0 rate-limited) from peer=8
```

Channel cut is Core's own relay gate in `ProcessAddrs`:
`vAddr.size() <= 10` = gossip (Core will relay it), `>= 11` = getaddr reply.

The stock line also reports `rate-limited`: addresses **dropped before addrman**.
`Getaddr addresses` / `Gossip addresses` below are the raw counts received on the
wire; subtract rate-limited to get what the node acted on.

Generated by `addr_daily_from_recvaddr.py` from the sha256-verified archives.
